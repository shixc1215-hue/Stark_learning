什么是模块？ 一个 .py 文件就是一个模块。你在之前课程里写的每个 Python 文件，其实都是模块！模块的好处是：把代码按功能拆分到不同文件，需要时 import 进来用，而不是全部塞进一个巨大的文件。

一、import 的 4 种写法

Python 提供了 4 种 import 写法，每种适用的场景不同。我们用 os（操作系统模块）和 datetime（日期时间模块）来举例：

# 写法1：import 整个模块
# 用的时候要写 "模块名.函数名"
import os
print(os.getcwd())          # 获取当前工作目录
print(os.path.exists("test.txt"))  # 判断文件是否存在

# 写法2：from 模块 import 具体功能
# 直接用函数名，不用写模块名前缀
from datetime import datetime
now = datetime.now()
print(now.strftime("%Y-%m-%d %H:%M"))  # 格式化输出：2026-06-07 10:35

# 写法3：from 模块 import * （导入全部，但不推荐！）
from os.path import *
# 这样可以用 exists()、join() 等，但不知道它们来自哪个模块
# ⚠️ 不推荐：容易命名冲突，且可读性差

# 写法4：import 模块 as 别名
# 当模块名太长，或想避免命名冲突时使用
import datetime as dt
today = dt.date.today()
print(today)  # 2026-06-07
实战建议：写 LLM 应用时，最常用的是写法 2（from ... import ...），因为 LLM 代码里经常要调 openai、langchain 等库，写 from openai import OpenAI 比写 import openai 然后每次写 openai.OpenAI() 更简洁。

二、自己写模块 —— 拆分你的项目

假设你的 LLM 项目结构长这样：

my_llm_project/
  ├── config.py        # 配置：API Key、模型参数
  ├── llm_client.py    # LLM 调用封装
  ├── prompt_templates.py  # Prompt 模板管理
  └── main.py          # 主程序入口

每个 .py 文件就是一个模块。来看怎么互相调用：

# ---------- config.py ----------
# 存放所有配置项
API_KEY = "your-api-key-here"
MODEL_NAME = "glm-4-flash"
MAX_TOKENS = 2048
BASE_URL = "https://open.bigmodel.cn/api/paas/v4"


# ---------- prompt_templates.py ----------
# 存放 Prompt 模板
SUMMARY_PROMPT = "你是一个金融分析师，请对以下数据进行总结分析："
SQL_PROMPT = "你是一个SQL专家，请根据以下需求生成SQL语句："


# ---------- llm_client.py ----------
# 封装 LLM 调用逻辑
from openai import OpenAI
from config import API_KEY, MODEL_NAME, BASE_URL

def ask_llm(prompt: str, user_input: str) -> str:
    """
    通用 LLM 调用函数
    参数：
      prompt: 系统提示词
      user_input: 用户输入
    返回：
      LLM 生成的回复文本
    """
    client = OpenAI(api_key=API_KEY, base_url=BASE_URL)
    response = client.chat.completions.create(
        model=MODEL_NAME,
        messages=[
            {"role": "system", "content": prompt},
            {"role": "user", "content": user_input}
        ]
    )
    return response.choices[0].message.content


# ---------- main.py ----------
# 主程序 —— 导入其他模块来使用
from llm_client import ask_llm
from prompt_templates import SUMMARY_PROMPT

# 直接用导入的函数，不用关心内部实现
data_summary = "不良资产项目3个，总余额5000万，本月回收率8.5%"
result = ask_llm(SUMMARY_PROMPT, data_summary)
print(result)
关键理解：当你写 from llm_client import ask_llm 时，Python 会去同一个目录下找 llm_client.py 文件，执行它里面的代码（但只运行到 def 定义，不会执行函数体），然后把 ask_llm 这个函数"搬过来"给你用。这就是模块化的核心思想。

三、__name__ == "__main__" 是什么意思？

你可能见过这个写法，它是模块开发的标准惯例：

# ---------- llm_client.py ----------
from openai import OpenAI
from config import API_KEY, MODEL_NAME, BASE_URL

def ask_llm(prompt: str, user_input: str) -> str:
    client = OpenAI(api_key=API_KEY, base_url=BASE_URL)
    response = client.chat.completions.create(
        model=MODEL_NAME,
        messages=[
            {"role": "system", "content": prompt},
            {"role": "user", "content": user_input}
        ]
    )
    return response.choices[0].message.content

# 这段代码只在"直接运行"这个文件时执行
# 被 import 导入时不会执行
if __name__ == "__main__":
    # 快速测试：直接跑一下看看函数是否正常
    test_result = ask_llm("你是一个助手", "你好")
    print(f"测试结果：{test_result}")

❌ 没有 __name__ 保护

当你 import llm_client 时，文件里所有顶层代码都会执行。
如果里面有测试代码，测试会自动跑，这不是你想要的。

✅ 有 __name__ 保护

只有你直接运行 python llm_client.py 时，测试代码才执行。
被 import 时，__name__ 不等于 "__main__"，测试被跳过。

🤖 LangChain 初体验：你的第一个 Chain~1-1.5h
LangChain 是什么？它是目前最流行的 LLM 应用开发框架。你可以把它理解为一个"LLM 乐高积木"——它把调用 LLM、管理 Prompt、解析输出、连接数据源等操作，封装成标准化的组件，你只需要拼装这些组件就能快速搭建 LLM 应用。之前你手写的 ask_llm() 函数，LangChain 用更优雅的方式实现了。

一、为什么需要框架？手写 vs 框架

❌ 手写（之前的方式）

from openai import OpenAI
client = OpenAI(api_key=key)
response = client.chat.completions.create(
    model="glm-4-flash",
    messages=[
        {"role":"system",
         "content":"你是AMC专家"},
        {"role":"user",
         "content":"什么是批量转让"}
    ]
)
result = response.choices[0].message.content

✅ LangChain（框架方式）

from langchain_openai import ChatOpenAI
from langchain_core.messages import (
    SystemMessage, HumanMessage
)

llm = ChatOpenAI(
    model="glm-4-flash",
    api_key=key, base_url=url
)
response = llm.invoke([
    SystemMessage(content="你是AMC专家"),
    HumanMessage(content="什么是批量转让")
])
print(response.content)

看起来差不多的对吧？LangChain 的价值在更复杂的场景中体现——当你需要模板管理、多步链式调用、输出解析、工具集成时，框架帮你省去大量重复代码。

二、LangChain 的核心概念（3 个组件）

LangChain 的核心就是 3 个组件的串联：

1

PromptTemplate（提示词模板）

把 Prompt 中的可变部分用占位符标记，运行时填入实际值。类似 SQL 的参数化查询。

2

LLM（大语言模型）

接收格式化后的 Prompt，调用模型 API 获取回复。

3

OutputParser（输出解析器）

把 LLM 返回的原始文本，解析成你需要的结构化格式（JSON、列表等）。

Chain = PromptTemplate → LLM → OutputParser
这三个组件像流水线一样串联，数据从左到右流动，最后输出结构化结果。这就是 LangChain 名字的由来——把多个组件"链接"成一条处理链。

# 方式1：用 from_template 创建（最常用）
prompt = ChatPromptTemplate.from_template(

# 方式2：更精细的控制（分别设置 system 和 user）
prompt2 = ChatPromptTemplate.from_messages([

messages2 = prompt2.format_messages(

六、Step 3：StrOutputParser —— 解析输出

from langchain_core.output_parsers import StrOutputParser

# 创建解析器
parser = StrOutputParser()

# 把 LLM 的 response 对象变成纯字符串
raw_response = llm.invoke([{"role": "user", "content": "你好"}])
print(type(raw_response))    # <class 'AIMessage'>
print(raw_response.content)  # "你好！有什么可以帮你的？"

parsed = parser.invoke(raw_response)
print(type(parsed))         # <class 'str'>
print(parsed)                # "你好！有什么可以帮你的？"
为什么要解析？因为 LLM 返回的是 AIMessage 对象（包含 content、response_metadata 等信息），而你的程序通常只需要纯文本。StrOutputParser 就是帮你提取纯文本。后面你还会学到 JsonOutputParser，可以直接让 LLM 输出 JSON 对象。

七、完整 Chain —— 三个组件串联

"""
LangChain 第一个完整 Chain 示例
功能：AMC 不良资产知识问答
流程：PromptTemplate → LLM → OutputParser
"""
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

# ---- 第1步：创建提示词模板 ----
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一位资深的AMC不良资产业务专家。"
               "请用专业但易懂的语言回答问题，"
               "回答控制在200字以内。"),
    ("user", "{question}")
])

# ---- 第2步：创建 LLM 实例 ----
llm = ChatOpenAI(
    model="glm-4-flash",
    api_key="your-api-key",
    base_url="https://open.bigmodel.cn/api/paas/v4/",
    temperature=0.3   # 低温度 = 更确定性的回答（适合知识问答）
)

# ---- 第3步：创建输出解析器 ----
parser = StrOutputParser()

# ---- 第4步：组装 Chain（用 | 管道符连接）----
chain = prompt | llm | parser

# ---- 第5步：运行 ----
question = "什么是不良资产的批量转让？和单个转让相比有什么优劣？"
result = chain.invoke({"question": question})
print(f"问：{question}")
print(f"答：{result}")
管道符 | 是 LangChain 的精髓：它来自 Python 的 LCEL（LangChain Expression Language）。prompt | llm | parser 的意思是"把 prompt 的输出传给 llm，再把 llm 的输出传给 parser"。数据像水流一样从左到右流过管道，非常直观。

八、进阶：带变量的 Chain + 打印中间结果

"""
进阶 Chain：多变量模板 + 查看中间步骤
"""
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

# 带多个变量的模板
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一位{role}，擅长{expertise}。"
               "请用{style}的风格回答用户问题。"),
    ("user", "{question}")
])

llm = ChatOpenAI(
    model="glm-4-flash",
    api_key="your-api-key",
    base_url="https://open.bigmodel.cn/api/paas/v4/",
    temperature=0.5
)

parser = StrOutputParser()

# 组装 Chain
chain = prompt | llm | parser

# ---- 运行并查看中间结果 ----
variables = {
    "role": "不良资产分析师",
    "expertise": "金融数据分析与风险评估",
    "style": "专业简洁",
    "question": "如何评估一个不良资产包的投资价值？"
}

# 方法1：直接获取最终结果
final_result = chain.invoke(variables)
print(f"最终结果：{final_result}\n")

# 方法2：分步执行，查看每一步的输出（调试利器！）
print("=== 分步调试 ===")

# Step 1：Prompt 生成 messages
formatted_messages = prompt.invoke(variables)
print(f"1. Prompt 输出（messages）：")
for msg in formatted_messages:
    print(f"   [{msg.type}] {msg.content}")

# Step 2：LLM 生成回复
llm_response = llm.invoke(formatted_messages)
print(f"\n2. LLM 输出（AIMessage）：")
print(f"   content: {llm_response.content}")

# Step 3：解析为纯文本
parsed_result = parser.invoke(llm_response)
print(f"\n3. 解析输出（纯文本）：{parsed_result}")

九、Chain 的两种批量调用方式

# 方式1：batch() —— 并行处理多个输入
questions = [
    "什么是不良资产证券化？",
    "DRO是什么处置方式？",

results = chain.batch([

    for q in questions

for q, r in zip(questions, results):
    print(f"Q: {q}")

    print("---")

# 方式2：invoke() 逐个调用（简单场景够用）
for q in questions:
    result = chain.invoke({
        "role": "AMC专家", "expertise": "不良资产",
        "style": "简洁", "question": q
    })
    print(f"A: {result[:80]}...")

📖 碎片知识：DSPy 框架概念~15min
DSPy 是什么？它是斯坦福大学开发的一个框架，核心理念是"用编程代替手写 Prompt"。传统方式是你手动写 Prompt、手动调优参数；DSPy 让你定义"输入→输出"的签名，框架自动帮你搜索最优的 Prompt 和演示示例。你可以把它理解为 "Prompt 的 AutoML"。

核心概念（3 分钟理解）

1. Signature（签名） —— 定义输入输出格式

# 传统方式：手写 Prompt
prompt = "请将以下文本总结为一句话：{text}"

# DSPy 方式：声明式定义
class Summarize(dspy.Signature):
    """将一段文本总结为一句话"""
    input_text = dspy.InputField(desc="需要总结的文本")
    summary = dspy.OutputField(desc="总结结果")

2. Module（模块） —— 可复用的处理单元

# DSPy 内置模块（类比 LangChain 的 Chain）
predictor = dspy.ChainOfThought(Summarize)  # 自动加 CoT 推理
result = predictor(input_text="长文本...")
print(result.summary)

3. Optimizer（优化器） —— 自动调优 Prompt

# 定义评估指标
def exact_match(example, pred, trace=None):
    return pred.summary == example.summary

# 自动搜索最优 Prompt（会在训练集上尝试多种策略）
optimizer = dspy.BootstrapFewShot(metric=exact_match)
optimized = optimizer.compile(predictor, trainset=train_examples)

今日题目：#20 有效的括号（简单）—— 栈（Stack）经典题，也是 LLM 应用开发中常见的模式（如追踪多轮对话的嵌套结构）。

题目描述：给定一个只包括 '(' ')' '{' '}' '[' ']' 的字符串，判断它是否有效。有效条件：每个左括号必须有同类型的右括号闭合，且顺序正确。

class Solution:
    def isValid(self, s: str) -> bool:
        """
        思路：用栈（list 模拟）匹配括号
        1. 遍历字符串的每个字符
        2. 遇到左括号 → 压入栈
        3. 遇到右括号 → 检查栈顶是否是对应的左括号
           - 是 → 弹出栈顶（匹配成功）
           - 否 → 返回 False（匹配失败）
        4. 遍历结束后，栈为空 → 全部匹配成功
        """
        # 左括号 → 右括号的映射
        pairs = {"(": ")", "{": "}", "[": "]"}
        stack = []

        for char in s:
            if char in pairs:          # 左括号 → 入栈
                stack.append(char)
            else:                      # 右括号 → 匹配
                if not stack:         # 栈空了，没有左括号可匹配
                    return False
                top = stack.pop()     # 取出栈顶的左括号
                if pairs[top] != char: # 类型不匹配
                    return False

        return len(stack) == 0  # 栈空 = 全部匹配

# 测试
sol = Solution()
print(sol.isValid("()"))        # True
print(sol.isValid("()[]{}"))    # True
print(sol.isValid("(]"))        # False
print(sol.isValid("([)]"))     # False
print(sol.isValid("{[]}"))     # True
栈的直觉：栈就是"后进先出"（LIFO）的结构，就像叠盘子——最后放上去的最先拿下来。Python 里直接用 list 模拟：append() 入栈，pop() 出栈。这题的核心思路是：遇到右括号时，它必须和最近一个没匹配的左括号配对——这正好是栈顶元素。
