🐍 HTTP 协议基础（一）：请求与响应 ~15min
💡 为什么学 HTTP？
你之前用 openai 库调用 LLM，那个库底层就是 HTTP 请求。理解 HTTP 原理后，你就能：
1. 用 requests 直接调用任何 REST API（不需要专门 SDK）
2. 理解报错原因（400/401/429/500 分别代表什么）
3. 开发 LLM 应用时，能调试和排查网络问题

HTTP 是什么？

HTTP（HyperText Transfer Protocol，超文本传输协议）是互联网的通用语言。你在浏览器打开任何网页、调用任何 API，底层都是 HTTP 请求。

一次 HTTP 请求的完整流程

你的 Python 程序 | | 发送请求（我要这个数据） v [ 服务器（API 端点）] | | 返回响应（这是你要的数据） v 你的 Python 程序（处理结果）

URL 的结构

https://open.bigmodel.cn/api/paas/v4/chat/completions
 |--|   |----------------| |--------------------------|
 协议        域名（服务器）          路径（具体接口）
  • https — 加密传输（HTTP 的安全版，API 调用必须用 https）
  • open.bigmodel.cn — 服务器地址（智谱 AI 的 API 服务器）
  • /api/paas/v4/chat/completions — 具体接口路径（聊天对话接口）

4 种常用请求方法

方法用途类比LLM 场景
GET 获取数据 去图书馆查书 查询模型列表、获取任务状态
POST 提交数据 提交一张申请表 发送对话消息、上传文件
PUT 更新数据 修改档案信息 更新配置、修改对话标题
DELETE 删除数据 销毁一份文件 删除对话历史
💡 只需记住两个
LLM 应用开发中，90% 的请求只有 GET 和 POST：GET 用来获取/查询，POST 用来发送对话内容。PUT 和 DELETE 偶尔用到。

常见 HTTP 状态码

状态码含义你可能遇到的情况
200成功请求正常返回
400请求格式错误传给 LLM 的参数写错了
401未授权API Key 错误或过期
403禁止访问没有该接口的调用权限
429请求太频繁超出了 API 的速率限制（rate limit）
500服务器内部错误LLM 服务提供商那边出了问题
⚠️ 记住这 4 个关键状态码
200 = 成功、401 = Key 错误、429 = 限流、500 = 服务器挂了。
你在调用 LLM API 时，遇到最多的就是这 4 个。

GET 请求：获取数据

先用一个公开 API 练手 —— 获取天气数据不需要 Key：

import requests

# ===== 最简单的 GET 请求 =====
response = requests.get("https://httpbin.org/get")
print(f"状态码: {response.status_code}")     # 200
print(f"响应类型: {type(response.text)}")       # <class 'str'>

# ===== 解析 JSON 响应 =====
data = response.json()                         # 自动把 JSON 字符串转为 Python 字典
print(f"你的 IP: {data['origin']}")
print(f"请求头: {data['headers']['User-Agent']}")
💡 response.json() 是最常用的方法
LLM API 返回的都是 JSON 格式。调用 response.json() 就能直接拿到 Python 字典，后续操作非常方便。

带参数的 GET 请求

查询参数（URL 中 ? 后面的部分）可以直接用 params 参数传入：

import requests

# ===== 带查询参数的 GET =====
# 实际 URL: https://httpbin.org/get?name=zhang&age=30
response = requests.get(
    "https://httpbin.org/get",
    params={"name": "zhang", "age": 30}
)
print(response.json()["args"])   # {'name': 'zhang', 'age': '30'}

# ===== 带请求头（模拟浏览器/设置 API Key） =====
response = requests.get(
    "https://httpbin.org/headers",
    headers={
        "User-Agent": "My-AMC-App/1.0",
        "Accept": "application/json"
    }
)
print(response.json()["headers"])

POST 请求：发送数据

LLM API 调用几乎都是 POST —— 你需要把对话消息发送给服务器：

import requests

# ===== 最简单的 POST 请求 =====
response = requests.post(
    "https://httpbin.org/post",
    json={"message": "Hello, LLM!", "role": "user"}
)
print(f"状态码: {response.status_code}")
print(f"收到的数据: {response.json()['json']}")

# ===== json 参数 vs data 参数 =====
# json 参数  → 自动设置 Content-Type: application/json，自动序列化
# data 参数  → 发送表单数据（Content-Type: application/x-www-form-urlencoded）
# LLM API 几乎都用 json 参数
⚠️ json vs data
调用 LLM API 用 json={...}（JSON 格式），不要用 data={...}（表单格式）。用错了服务器会返回 400 错误。

错误处理：处理网络异常

HTTP 请求可能失败（超时、网络断开、服务器报错）。加上异常处理：

import requests

def safe_get(url, timeout=10):
    """安全的 GET 请求，带完整的错误处理"""
    try:
        response = requests.get(url, timeout=timeout)
        response.raise_for_status()  # 如果状态码不是 200，抛出异常

        return response.json()

    except requests.exceptions.Timeout:
        print(f"⏳ 请求超时（{timeout}s）")
    except requests.exceptions.ConnectionError:
        print("🔌 网络连接失败，请检查网络")
    except requests.exceptions.HTTPError as e:
        if e.response.status_code == 401:
            print("🔒 API Key 错误或过期")
        elif e.response.status_code == 429:
            print("⏳ 请求太频繁，请稍后重试")
        elif e.response.status_code == 500:
            print("💨 服务器内部错误，请稍后重试")
        else:
            print(f"❌ HTTP 错误: {e.response.status_code}")
    except requests.exceptions.RequestException as e:
        print(f"❌ 请求异常: {e}")

    return None

# 测试
result = safe_get("https://httpbin.org/get")
print(f"结果: {result}")

# 测试 404 错误
bad = safe_get("https://httpbin.org/status/404")
print(f"404 结果: {bad}")
💡 三行代码记住错误处理模式
requests.get(url, timeout=10) → 加超时
response.raise_for_status() → 非成功状态码自动抛异常
try/except → 分类型处理不同错误

这是调用任何 HTTP API的标准模板，直接套用。

看懂 API 文档（核心能力）

调用任何 API 之前，先看文档需要什么参数。以智谱为例：

智谱 AI Chat API 文档摘要 地址: POST https://open.bigmodel.cn/api/paas/v4/chat/completions 请求头: Authorization: Bearer {你的API Key} 请求体(JSON): { "model": "glm-4-flash", "messages": [ {"role": "system", "content": "你是助手"}, {"role": "user", "content": "你好"} ] } 响应(JSON): { "choices": [{"message": {"content": "你好！有什么可以帮你的？"}}] }
💡 看文档的 3 个关键点
1. URL：请求发到哪个地址
2. 请求头：需要哪些认证信息（API Key 放这里）
3. 请求体：需要传什么参数（JSON 格式）

任何 API 文档都是这个套路，掌握后可以调用任何 API。

用 requests 调用智谱 AI（纯 HTTP，不用 SDK）

import requests

# ===== 配置 =====
API_KEY = "你的智谱API Key"
API_URL = "https://open.bigmodel.cn/api/paas/v4/chat/completions"

def call_zhipu(prompt, model="glm-4-flash"):
    """
    用 requests 直接调用智谱 AI API（不依赖 openai SDK）
    这是最原始的 HTTP 调用方式，让你理解底层原理
    """
    headers = {
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json"
    }

    body = {
        "model": model,
        "messages": [
            {"role": "system", "content": "你是AMC不良资产领域的AI助手。"},
            {"role": "user", "content": prompt}
        ],
        "temperature": 0.7
    }

    try:
        response = requests.post(API_URL, headers=headers, json=body, timeout=30)
        response.raise_for_status()

        data = response.json()
        content = data["choices"][0]["message"]["content"]

        # 打印 token 用量
        usage = data.get("usage", {})
        print(f"🕑 Token 用量: 输入 {usage.get('prompt_tokens','?')} + 输出 {usage.get('completion_tokens','?')} = {usage.get('total_tokens','?')}")

        return content

    except requests.exceptions.HTTPError as e:
        print(f"❌ API 错误 [{e.response.status_code}]: {e.response.text}")
    except requests.exceptions.Timeout:
        print("⏳ 请求超时")
    except Exception as e:
        print(f"❌ 未知错误: {e}")

    return None

# ===== 测试 =====
result = call_zhipu("请用3句话解释什么是不良资产")
print(f"\n🤖 智谱回答:\n{result}")
💡 对比 openai 库和 requests
你会发现，用 requests 调用和用 openai 库调用的请求结构完全一样：
- 请求头都带 Authorization: Bearer {API_KEY}
- 请求体都有 model 和 messages

openai 库只是帮你自动拼装了这些 HTTP 请求而已。

设计统一接口：一个函数调多个模型

先用 Day 5 学的函数封装，把不同模型的调用统一成一个函数：

import requests
import json
from datetime import datetime

# ===== 模型配置表 =====
# 每个模型：名称、API地址、Key、请求头格式
MODEL_CONFIGS = {
    "glm-4-flash": {
        "name": "智谱 GLM-4-Flash",
        "url": "https://open.bigmodel.cn/api/paas/v4/chat/completions",
        "api_key": "你的智谱API Key",
        "headers": lambda key: {
            "Authorization": f"Bearer {key}",
            "Content-Type": "application/json"
        },
    },
    "qwen-turbo": {
        "name": "通义千问 Qwen-Turbo",
        "url": "https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions",
        "api_key": "你的通义API Key（可选）",
        "headers": lambda key: {
            "Authorization": f"Bearer {key}",
            "Content-Type": "application/json"
        },
    },
}

def call_llm(prompt, model_key="glm-4-flash", system_prompt=None, timeout=30):
    """
    统一的 LLM 调用函数
    - 传入模型名称，自动查找配置
    - 统一的请求/响应格式
    - 统一的错误处理
    """
    config = MODEL_CONFIGS.get(model_key)
    if not config:
        print(f"❌ 未知模型: {model_key}")
        return None

    headers = config["headers"](config["api_key"])

    messages = []
    if system_prompt:
        messages.append({"role": "system", "content": system_prompt})
    messages.append({"role": "user", "content": prompt})

    body = {
        "model": model_key,
        "messages": messages,
        "temperature": 0.7
    }

    try:
        response = requests.post(
            config["url"], headers=headers, json=body, timeout=timeout
        )
        response.raise_for_status()

        data = response.json()
        content = data["choices"][0]["message"]["content"]
        usage = data.get("usage", {})

        return {
            "model": config["name"],
            "content": content,
            "prompt_tokens": usage.get("prompt_tokens", 0),
            "completion_tokens": usage.get("completion_tokens", 0),
            "total_tokens": usage.get("total_tokens", 0),
            "elapsed_ms": response.elapsed.total_seconds() * 1000,
        }

    except requests.exceptions.HTTPError as e:
        return {"model": config["name"], "error": f"HTTP {e.response.status_code}: {e.response.text[:200]}"}
    except requests.exceptions.Timeout:
        return {"model": config["name"], "error": "请求超时"}
    except Exception as e:
        return {"model": config["name"], "error": str(e)}

高级版：交互式对比工具

输入 Prompt → 多个模型同时回答 → 并排展示：

import requests
import time

# ===== 简化版交互对比工具 =====
def compare_models():
    """
    交互式 LLM 对比工具
    输入 Prompt → 同时调用多个模型 → 并排展示结果
    """
    print("=" * 70)
    print("🤖 LLM 模型对比工具 v1.0")
    print("=" * 70)
    print("输入 Prompt，将同时发送给多个模型进行对比")
    print("输入 'q' 退出\n")

    while True:
        prompt = input("💬 请输入 Prompt: ").strip()
        if prompt.lower() == "q":
            print("👋 再见！")
            break
        if not prompt:
            continue

        # 并发调用（虽然用串行，但结构是可扩展的）
        print(f"\n🕑 正在调用模型...")
        start_time = time.time()

        model_results = {}
        for model_key, config in MODEL_CONFIGS.items():
            result = call_llm(prompt, model_key=model_key)
            if result and "error" not in result:
                model_results[config["name"]] = result
            else:
                model_results[config["name"]] = {"error": result.get("error", "调用失败") if result else "配置缺失"}

        elapsed = time.time() - start_time

        # ===== 格式化输出 =====
        print(f"\n{'='*70}")
        print(f"📊 对比结果（总耗时 {elapsed:.2f}s）")
        print(f"{'='*70}")

        for model_name, result in model_results.items():
            print(f"\n📌 【{model_name}】")
            if "error" in result:
                print(f"   ❌ {result['error'][:100]}")
            else:
                print(f"   🕑 耗时: {result['elapsed_ms']:.0f}ms | Token: {result['total_tokens']}")
                print(f"   💬 回答:\n   {result['content']}")
                print(f"   {'-'*60}")

        # 用户评分
        print(f"\n🌟 请给各模型打分（1-5分，回车跳过）:")
        for model_name in model_results:
            score = input(f"   {model_name}: ").strip()
            if score.isdigit() and 1 <= int(score) <= 5:
                print(f"   ✅ {model_name}: {score}分")

        print("\n" + "="*70 + "\n")

💡 模型对比的评估维度
对比模型时关注这些维度：
1. 准确性：回答是否正确、是否有幻觉
2. 相关性：是否回答了你问的问题
3. 完整性：是否遗漏了重要信息
4. 语言质量：中文表达是否流畅自然
5. 响应速度：延迟是否可接受
6. 成本：Token 消耗是否合理

openai SDK vs requests 对比总结

维度openai SDKrequests 裸调
代码量少（封装好了）多（要拼 headers/body）
依赖需要安装 SDKrequests 几乎必装
兼容性只支持 OpenAI 格式任何 API 都能调
调试错误被 SDK 包了一层直接看到 HTTP 响应
推荐场景OpenAI 兼容的 API不兼容的 API / 调试
最佳实践优先用 SDKSDK 不好用时再 requests
📖 碎片知识：API Key 安全最佳实践 ~15min
🎯 API Key = 你的钱包密码
API Key 泄露 = 别人可以用你的账户调 API，消耗你的额度，产生费用。在 GitHub 上泄露 Key 的案例非常多。
⚠️ 千万不要做这些事
❌ 把 API Key 写死在代码里：API_KEY = "abc123xyz..."
❌ 把代码（含 Key）推到 GitHub / Gitee 公开仓库
❌ 把 Key 发到聊天群、邮件等不安全的地方
❌ 多个环境（开发/生产）用同一个 Key

正确做法：用 .env 文件管理密钥

📚 今日题目：LeetCode #268 丢失的数字

难度：简单  |  标签：数组、位运算、数学

题目：给定一个包含 [0, n] 中 n 个不同数字的数组 nums，找出丢失的那个数字。

示例：nums = [3, 0, 1] → 2

示例：nums = [0, 1] → 2

示例：nums = [9, 6, 4, 2, 3, 5, 7, 0, 1] → 8

思路提示

思路一：排序后看哪个位置不对。思路二：数学求和（0到n的和 - 数组元素和 = 丢失的数）。思路三：异或运算（XOR），每个数和自己异或为0，成对出现的数异或后消失，最后剩下的就是缺失的。

方法一：数学求和（最直观）

def missingNumber(nums):
    """
    数学方法：完整序列的和 - 数组元素的和 = 缺失的数
    时间 O(n)，空间 O(1)
    """
    n = len(nums)
    total_sum = n * (n + 1) // 2  # 0 + 1 + 2 + ... + n
    actual_sum = sum(nums)
    return total_sum - actual_sum

print(missingNumber([3, 0, 1]))                        # 2
print(missingNumber([0, 1]))                            # 2
print(missingNumber([9, 6, 4, 2, 3, 5, 7, 0, 1]))      # 8

方法二：异或运算（最优解）

def missingNumber_xor(nums):
    """
    异或方法：利用 XOR 的性质
    - a ^ a = 0（相同的数异或为0）
    - a ^ 0 = a（任何数和0异或为自己）
    - 异或满足交换律和结合律

    把 0~n 和数组所有元素一起异或，
    成对出现的数字会互相抵消为0，
    最后剩下的就是缺失的数字。
    """
    n = len(nums)
    result = 0

    # 先异或 0~n
    for i in range(n + 1):
        result ^= i

    # 再异或数组中的每个元素
    for num in nums:
        result ^= num

    return result

print(missingNumber_xor([3, 0, 1]))                        # 2
print(missingNumber_xor([0, 1]))                            # 2
print(missingNumber_xor([9, 6, 4, 2, 3, 5, 7, 0, 1]))      # 8
💡 本题要点
1. 数学求和法最简单，公式 n*(n+1)//2 是高斯求和公式
2. 异或法是经典技巧 —— 在位运算类题目中经常用到
3. 面试时先写数学法（简单不出错），再提异或法（加分项）
