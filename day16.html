🐍 pandas 基础（一）：读写 CSV ~25min
💡 为什么要学 pandas？
pandas 是 Python 数据分析的瑞士军刀。作为数据开发工程师，你天天用 SQL 处理数据 —— pandas 就是 Python 版的 SQL。

在 LLM 应用中，pandas 的用途：
1. 读取业务数据 CSV，预处理后传给 LLM 做分析
2. 处理 LLM 返回的结构化数据
3. 管理知识库的元数据（文档列表、标签、日期等）
🎯 两个核心数据结构
DataFrame = 二维表格，就像 Excel 的一张 Sheet，也像 SQL 的一张表
Series = 一维数据，就像表格中的一列

90% 的时间你只用 DataFrame，Series 是 DataFrame 的组成部分。

🐍 pandas 基础（二）：数据筛选 ~20min
🎯 SQL 思维翻译法
你已经精通 SQL，学 pandas 最快的方式就是把 SQL 查询翻译成 pandas 代码。下面每条操作都配上对应的 SQL，帮你快速建立映射。

2.1 条件筛选（WHERE）

import pandas as pd
df = pd.read_csv("data/amc_projects.csv", encoding="utf-8-sig")

# ===== SQL: SELECT * FROM df WHERE acquire_cost > 800 =====
high_cost = df[df["acquire_cost"] > 800]
print(f"收购成本 > 800万 的项目: {len(high_cost)} 个")
print(high_cost[["project_name", "acquire_cost"]])

# ===== SQL: WHERE region = '华东' AND status = '处置中' =====
mask = (df["region"] == "华东") & (df["status"] == "处置中")
result = df[mask]
print(f"\n华东地区处置中的项目: {len(result)} 个")

# ===== SQL: WHERE business_type IN ('债权转让', '债务重组') =====
types = ["债权转让", "债务重组"]
result2 = df[df["business_type"].isin(types)]
print(f"\n债权转让或债务重组项目: {len(result2)} 个")

# ===== SQL: WHERE project_name LIKE '%地产%' =====
result3 = df[df["project_name"].str.contains("地产")]
print(f"\n项目名含'地产'的: {len(result3)} 个")
print(result3[["project_name"]])
⚠️ 条件组合必须用括号 + 位运算符
df[(条件1) & (条件2)] — 用 & 不是 and
df[(条件1) | (条件2)] — 用 | 不是 df[~条件] — 取反用 ~ 不是 not

这是 pandas 最常见的坑之一 —— 忘了加括号会导致 ValueError。

2.2 选取列和行（SELECT + 行索引）

# ===== SQL: SELECT project_name, acquire_cost FROM df =====
cols = df[["project_name", "acquire_cost"]]

# ===== loc（按标签选） =====
# SQL: SELECT * FROM df WHERE region = '华东' LIMIT 3
subset = df.loc[df["region"] == "华东", ["project_name", "acquire_cost"]].head(3)

# ===== iloc（按位置选，从 0 开始） =====
# 选取前 3 行的前 4 列
first_3 = df.iloc[:3, :4]

# ===== 新增计算列（SQL: SELECT *, acquire_cost - recovery_amount AS gap） =====
df["net_recovery_rate"] = (
    (df["recovery_amount"] - df["disposal_cost"]) / df["acquire_cost"] * 100
).round(2)
print(df[["project_name", "acquire_cost", "recovery_amount", "net_recovery_rate"]])
💡 loc vs iloc 记忆法
loc = label（标签）→ 用列名和条件
iloc = integer（整数）→ 用行号和列号

推荐：日常用 loc，更安全（不怕列顺序变化）。iloc 在需要按位置切片时用。
🐍 pandas 基础（三）：分组聚合 ~15min
🎯 groupby = SQL 的 GROUP BY
分组聚合是数据分析的核心 —— 按某个维度（地区/业务类型/状态）把数据分组，然后对每组做统计（求和/均值/计数）。你天天写 SQL 的 GROUP BY，pandas 版的语法其实更简洁。 
import pandas as pd
df = pd.read_csv("data/amc_projects.csv", encoding="utf-8-sig")

# ===== 1. 按 region 分组，计算平均收购成本 =====
# SQL: SELECT region, AVG(acquire_cost), COUNT(*) FROM df GROUP BY region
region_stats = df.groupby("region").agg(
    项目数=("project_name", "count"),
    平均收购成本=("acquire_cost", "mean"),
    总收购成本=("acquire_cost", "sum"),
    平均回收金额=("recovery_amount", "mean"),
).round(2)
print("=== 按地区统计 ===")
print(region_stats)

# ===== 2. 按 business_type 分组 =====
type_stats = df.groupby("business_type").agg(
    项目数=("project_name", "count"),
    平均回收金额=("recovery_amount", "mean"),
    总回收金额=("recovery_amount", "sum"),
).round(2)
print("\n=== 按业务类型统计 ===")
print(type_stats)

# ===== 3. 按 status 分组 =====
status_stats = df.groupby("status").agg(
    项目数=("project_name", "count"),
    平均收购成本=("acquire_cost", "mean"),
).round(2)
print("\n=== 按处置状态统计 ===")
print(status_stats)

# ===== 4. 多维度分组 =====
# SQL: SELECT region, status, COUNT(*), AVG(acquire_cost) GROUP BY region, status
multi = df.groupby(["region", "status"]).agg(
    项目数=("project_name", "count"),
    平均收购成本=("acquire_cost", "mean"),
).round(2)
print("\n=== 按地区+状态交叉统计 ===")
print(multi)

常用聚合函数对照

聚合操作pandas 写法SQL 对应
计数("列名", "count")COUNT(*)
求和("列名", "sum")SUM(列名)
均值("列名", "mean")AVG(列名)
最大值("列名", "max")MAX(列名)
最小值("列名", "min")MIN(列名)
中位数("列名", "median")PERCENTILE_CONT(0.5)
标准差("列名", "std")STDDEV(列名)
💡 pandas 的 agg 命名参数
.agg(自定义名=("列名", "函数")) 这种写法可以给结果列起中文名，输出更易读。这是 pandas 2.0+ 推荐的写法。

如果想用多个聚合：.agg(总成本=("acquire_cost", "sum"), 平均成本=("acquire_cost", "mean"))
🤖 实战：pandas + LLM 数据分析 ~1.5h
💡 为什么要把数据传给 LLM？
pandas 能算出数字，但不能自动写出分析结论。而 LLM 擅长把数字翻译成人类可读的分析文本。

这就是 "数据 + AI" 的结合点：
pandas 统计数据 → 格式化为文本 → LLM 生成分析报告
1

用 pandas 生成数据摘要

先把数据统计出来，转成 LLM 能理解的文本格式：

import pandas as pd
from pathlib import Path

# 读取数据
df = pd.read_csv("data/amc_projects.csv", encoding="utf-8-sig")

# 计算净回收率
df["net_recovery_rate"] = (
    (df["recovery_amount"] - df["disposal_cost"]) / df["acquire_cost"] * 100
).round(2)

# ===== 生成数据摘要（给 LLM 看的） =====

# 1. 整体概况
total_cost = df["acquire_cost"].sum()
total_recovery = df["recovery_amount"].sum()
total_disposal = df["disposal_cost"].sum()
overall_rate = ((total_recovery - total_disposal) / total_cost * 100)
total_projects = len(df)
closed = len(df[df["status"] == "已结案"])
ongoing = len(df[df["status"] == "处置中"])

# 2. 按地区统计
region_stats = df.groupby("region").agg(
    项目数=("project_name", "count"),
    总收购成本=("acquire_cost", "sum"),
    总回收金额=("recovery_amount", "sum"),
    总处置费用=("disposal_cost", "sum"),
).round(2)

# 3. 按业务类型统计
type_stats = df.groupby("business_type").agg(
    项目数=("project_name", "count"),
    总收购成本=("acquire_cost", "sum"),
    总回收金额=("recovery_amount", "sum"),
    总处置费用=("disposal_cost", "sum"),
).round(2)

# ===== 把统计数据格式化为文本 =====
summary = f"""
## AMC 不良资产项目数据摘要

### 一、整体概况
- 项目总数: {total_projects} 个（已结案 {closed} 个，处置中 {ongoing} 个）
- 总收购成本: {total_cost} 万元
- 总回收金额: {total_recovery} 万元
- 总处置费用: {total_disposal} 万元
- 整体净回收率: {overall_rate:.2f}%

### 二、按地区统计
{region_stats.to_string()}

### 三、按业务类型统计
{type_stats.to_string()}

### 四、各项目明细
{df[["project_name", "region", "business_type", "acquire_cost",
      "recovery_amount", "disposal_cost", "net_recovery_rate", "status"
     ]].to_string(index=False)}
"""

print(summary)

把数据摘要传给 LLM 生成分析报告

用智谱 AI 的 API，让 LLM 基于数据生成专业的中文分析报告：

from openai import OpenAI

client = OpenAI(
    api_key="你的智谱API Key",
    base_url="https://open.bigmodel.cn/api/paas/v4"
)

# 选择分析维度（模拟用户交互）
print("请选择分析维度:")
print("1. 整体概况分析")
print("2. 地区对比分析")
print("3. 业务类型分析")
print("4. 综合分析报告")
choice = input("请输入选项(1-4): ")

dimension_map = {
    "1": "整体概况",
    "2": "地区对比",
    "3": "业务类型",
    "4": "综合分析",
}
dimension = dimension_map.get(choice, "综合分析")

# 构建 Prompt
prompt = f"""你是AMC不良资产处置领域的数据分析专家。
请根据以下数据摘要，撰写一份专业的{dimension}分析报告。

报告要求：
1. 用中文撰写，语言简洁专业
2. 引用具体数字支撑结论
3. 指出数据中的异常或值得关注的问题
4. 给出处置建议（2-3条）
5. 格式清晰，使用小标题和要点列表
6. 控制在 500 字以内

数据摘要：
{summary}
"""

response = client.chat.completions.create(
    model="glm-4-flash",
    messages=[
        {"role": "system", "content": "你是AMC不良资产数据分析师，擅长从数据中发现问题和机会。"},
        {"role": "user", "content": prompt}
    ],
    temperature=0.7,
)

report = response.choices[0].message.content
print("\n" + "=" * 50)
print(f"📊 {dimension}分析报告")
print("=" * 50)
print(report)

# 保存报告到文件
from datetime import datetime
timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
report_file = f"data/analysis_report_{timestamp}.txt"
Path(report_file).write_text(report, encoding="utf-8")
print(f"\n报告已保存: {report_file}")

验证 LLM 输出的准确性

AI 分析虽然专业，但可能有幻觉（数字说错、编造数据）。必须验证！

# ===== 验证技巧：让 LLM 先做计算，再和 pandas 结果对比 =====

# 方法1：直接对比关键数字
print("=== 验证 LLM 报告中的关键数字 ===")
print(f"实际总收购成本: {total_cost} 万元")
print(f"实际总回收金额: {total_recovery} 万元")
print(f"实际整体净回收率: {overall_rate:.2f}%")

# 方法2：让 LLM 自己做计算题，检查数学能力
calc_prompt = f"""根据以下数据，请计算：
1. 华东地区的总收购成本是多少？
2. 债权转让类项目的平均回收金额是多少？
3. 净回收率最高的项目是哪个？

数据：
{df.to_string(index=False)}

请给出计算过程和结果。
"""

response = client.chat.completions.create(
    model="glm-4-flash",
    messages=[{"role": "user", "content": calc_prompt}],
    temperature=0.0,  # temperature=0 减少随机性，适合计算题
)
print(response.choices[0].message.content)

# 方法3：pandas 独立验证
print("\n=== pandas 独立验证 ===")
print(f"华东地区总收购成本: {df[df['region']=='华东']['acquire_cost'].sum()} 万元")
print(f"债权转让平均回收金额: {df[df['business_type']=='债权转让']['recovery_amount'].mean():.2f} 万元")
best = df.loc[df["net_recovery_rate"].idxmax()]
print(f"净回收率最高: {best['project_name']} ({best['net_recovery_rate']}%)")
💡 LLM 做数学运算的局限
永远不要让 LLM 做精确计算！LLM 是语言模型，不是计算器。

正确做法：
1. pandas 算数字（精确可靠）
2. LLM 写分析（语言表达专业）
3. 人工验证关键数据（防止幻觉）

在上面的代码中，我们用 temperature=0.0 做计算题可以稍微提高准确率，但仍不保证 100% 正确。

🎯 作为 LLM 应用工程师，你必须了解模型选型
什么时候用 GPT-4 / Claude（闭源 API）？什么时候用 Qwen / Llama（开源自部署）？这不是技术信仰问题，而是成本、数据安全、性能的综合权衡。
维度闭源模型（GPT-4 / Claude / GLM）开源模型（Qwen / Llama / DeepSeek）
使用方式 API 调用，按 token 付费 下载到本地或云端服务器运行
费用 按量付费，大规模使用成本高 一次部署，无限调用（硬件成本）
数据安全 数据发送到第三方服务器 数据不出本地，完全可控
性能 旗舰级效果最好（GPT-4o / Claude-3.5） 70B+ 接近闭源，小模型差距明显
延迟 网络延迟 + 排队 本地推理更快（需足够 GPU）
定制化 只能通过 Prompt 工程 可微调注入领域知识
适用场景 通用任务、快速原型、非敏感数据 金融/医疗等敏感数据、大规模调用、领域微调

📚 今日题目：LeetCode #169 多数元素

难度：简单  |  标签：数组、计数

题目：给定一个大小为 n 的数组 nums，返回其中出现次数超过 n/2 的元素。你可以假设这个元素一定存在。

示例：[3, 2, 3] → 3

示例：[2, 2, 1, 1, 1, 2, 2] → 2

思路提示

先想简单方法（字典计数），再了解一个巧妙的算法：**摩尔投票法**（Boyer-Moore），只需要 O(1) 额外空间。

方法一：字典计数（最直观）

def majorityElement(nums):
    """方法一：字典计数 —— 直观、易懂、面试可写"""
    counts = {}
    for num in nums:
        counts[num] = counts.get(num, 0) + 1
        if counts[num] > len(nums) // 2:
            return num
    return -1  # 理论上不会走到这里

print(majorityElement([3, 2, 3]))              # 3
print(majorityElement([2, 2, 1, 1, 1, 2, 2])) # 2

方法二：摩尔投票法（最优解）

def majorityElement_moore(nums):
    """
    摩尔投票法核心思想：
    - 假设第一个元素是"候选人"
    - 遇到相同的就"票数+1"，遇到不同的就"票数-1"
    - 票数归零就换下一个候选人
    - 因为多数元素出现次数 > n/2，最后一定"赢"
    """
    candidate = None
    count = 0

    for num in nums:
        if count == 0:
            candidate = num    # 票数归零，换候选人
        if num == candidate:
            count += 1        # 相同，票数+1
        else:
            count -= 1        # 不同，票数-1

    return candidate

print(majorityElement_moore([3, 2, 3]))              # 3
print(majorityElement_moore([2, 2, 1, 1, 1, 2, 2])) # 2
💡 本题要点
1. 字典计数是万能解法，先写出来保证正确
2. 摩尔投票法是经典算法，面试加分项 —— O(n) 时间 + O(1) 空间
3. 摩尔投票法只适用于保证存在多数元素的情况。如果没有保证，需要二次验证
