完善搜索模块 search.py —— 增加模糊匹配

Day 10 的搜索只做了精确关键词匹配，现在增加模糊匹配：当用户输入的关键词在知识库中没有完全命中时，用 in 运算符做子串包含匹配。

# search.py —— 在原有基础上增加模糊匹配

def search_knowledge(query: str, knowledge_base: list) -> list:
    """在知识库中搜索匹配的问答对"""
    results = []

    for item in knowledge_base:
        question = item["question"].lower()   # 转小写，统一比较
        keywords = item["keywords"].lower()
        query_lower = query.lower()

        # 匹配策略 1：精确关键词匹配（优先级高）
        exact_match = any(
            kw in query_lower
            for kw in keywords.split(",")
        )

        # 匹配策略 2：模糊子串匹配（兜底）
        fuzzy_match = (
            query_lower in question
            or question in query_lower
        )

        if exact_match:
            item["match_type"] = "exact"   # 标记匹配类型
            results.append(item)
        elif fuzzy_match and not exact_match:
            item["match_type"] = "fuzzy"
            results.append(item)

    # 按匹配优先级排序：精确 > 模糊
    results.sort(key=lambda x: (0 if x["match_type"] == "exact" else 1))
    return results
💡 代码讲解：
  • .lower() —— 把字符串全部转小写，这样 "AMC" 和 "amc" 都能匹配上。这是文本匹配的常见做法
  • any() —— Python 内置函数，只要列表中有任意一个为 True 就返回 True。类似 SQL 的 EXISTS
  • lambda x: (0 if ... else 1) —— 匿名函数，用 sort 排序时：返回 0 的排前面，返回 1 的排后面
  • 这里用到了你上周学的列表、字典、循环、函数、字符串操作，一举多得

完善主程序 main.py —— 增加退出和帮助

让程序支持 quit / exit 退出命令，以及 help 查看使用说明。

# main.py —— 完整的主程序循环

import json
from search import search_knowledge
from llm_client import ask_llm

def load_knowledge(filepath: str) -> list:
    """加载知识库 JSON 文件"""
    try:
        with open(filepath, "r", encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        print("⚠️ 知识库文件未找到，请检查路径")
        return []

def show_help():
    """显示帮助信息"""
    print("""
📝 不良资产知识问答助手 —— 使用说明
━━━━━━━━━━━━━━━━━━━━━━━━━━
  直接输入问题    →  先搜索知识库，未匹配则调用 LLM
  输入 help       →  查看本帮助
  输入 quit/exit  →  退出程序
  输入 history     →  查看对话历史
━━━━━━━━━━━━━━━━━━━━━━━━━━
""")

def main():
    """主程序入口"""
    knowledge = load_knowledge("knowledge_base.json")
    chat_history = []   # 对话历史列表

    print("💬 不良资产知识问答助手（输入 help 查看帮助，quit 退出）")

    while True:          # 无限循环，直到用户输入 quit
        user_input = input("\n📝 你的问题：").strip()

        # ---- 退出命令 ----
        if user_input.lower() in ["quit", "exit", "q"]:
            print("� 再见！对话已保存。")
            break          # 跳出 while 循环，程序结束

        # ---- 帮助命令 ----
        elif user_input.lower() == "help":
            show_help()
            continue      # 跳过本轮，重新循环

        # ---- 历史记录命令 ----
        elif user_input.lower() == "history":
            if not chat_history:
                print("  暂无对话记录")
            else:
                print("\n🕑 对话历史：")
                for i, msg in enumerate(chat_history, 1):
                    role = "💬 你" if msg["role"] == "user" else "🤖 AI"
                    print(f"  {i}. {role}: {msg['content'][:80]}...")
            continue

        # ---- 空输入跳过 ----
        elif not user_input:
            continue

        # ---- 正常问答流程 ----
        # 第一步：本地知识库搜索
        results = search_knowledge(user_input, knowledge)

        if results:
            # 找到匹配，直接返回知识库答案
            answer = results[0]["answer"]
            source = results[0]["source"]
            print(f"\n📖 【知识库匹配】：{answer}")
            print(f"  → 来源：{source}")
            answer_text = answer
        else:
            # 没有匹配，调用 LLM
            print("  🔄 知识库未匹配，正在调用 LLM...")
            answer_text = ask_llm(user_input)
            print(f"\n🤖 【LLM 回答】：{answer_text}")

        # 保存到对话历史
        chat_history.append({"role": "user", "content": user_input})
        chat_history.append({"role": "assistant", "content": answer_text})

    # ---- 退出时保存对话历史 ----
    try:
        with open("chat_history.json", "w", encoding="utf-8") as f:
            json.dump(chat_history, f, ensure_ascii=False, indent=2)
        print("💾 对话已保存到 chat_history.json")
    except Exception as e:
        print(f"⚠️ 保存失败：{e}")

# 程序入口
if __name__ == "__main__":
    main()
💡 代码讲解 —— 几个关键 Python 知识点：
  • while True —— 无限循环，只有遇到 break 才会退出。命令行交互程序的标配写法
  • .strip() —— 去掉字符串两端的空格和换行。用户输入 " 你好 " 会变成 "你好"
  • .lower() in ["quit", "exit", "q"] —— 判断用户输入（转小写后）是否在列表中。相当于 SQL 的 IN
  • if __name__ == "__main__" —— Python 的标准入口写法。意思是"只有直接运行这个文件时才执行 main()"，被其他文件 import 时不执行
  • enumerate(chat_history, 1) —— 遍历列表的同时给每个元素编号，从 1 开始。输出就是 1. 2. 3. 而不是 0. 1. 2.
  • f"...{msg['content'][:80]}..." —— 切片语法，只取前 80 个字符，避免历史记录太长刷屏
  • ensure_ascii=False —— 让 json.dump 正常输出中文，否则中文字符会变成 \uXXXX 编码

💡 Git 命令讲解（每个都很有用）：
  • git init —— 在当前目录创建一个 .git 隐藏文件夹，开始跟踪代码变化
  • git add . —— 把所有修改过的文件放进"暂存区"（staging area），相当于"我准备提交这些"
  • git status —— 查看当前状态：哪些文件修改了、哪些已暂存、哪些未跟踪。类似 SQL 查询的预览
  • git commit -m "说明" —— 把暂存区的文件正式保存为一个版本（commit）。-m 后面是这次修改的说明
  • git remote add origin URL —— 把本地仓库关联到一个远程地址。origin 是默认的远程名称
  • git push —— 把本地的 commit 推送到远程仓库（GitHub）

🟢 LeetCode #217：存在重复元素（简单）

题目：给你一个整数数组 nums，判断是否存在重复元素。存在返回 True，不存在返回 False。

示例：

输入：nums = [1, 2, 3, 1]
输出：True        # 1 出现了两次

输入：nums = [1, 2, 3, 4]
输出：False       # 所有元素都不重复

思路：把列表转成集合（set），集合自动去重。如果去重后长度变短了，说明有重复。

def containsDuplicate(nums: list[int]) -> bool:
    """判断数组中是否有重复元素"""
    return len(nums) != len(set(nums))
    #           ^^^^^^^^     ^^^^^^^^^^^^^^^^
    #           原始长度      转集合后的长度
    #           不相等 = 有元素被去掉了 = 有重复

# 测试
print(containsDuplicate([1, 2, 3, 1]))   # True
print(containsDuplicate([1, 2, 3, 4]))   # False
💡 为什么用 set？：
  • set() 是 Python 的集合类型，有两个核心特性：去重（重复元素只保留一个）和快速查找（O(1) 复杂度）
  • len(set(nums)) 就是去重后的元素个数。和原长度一比就知道有没有重复
  • 这题还有另一种写法：seen = set(); for n in nums: if n in seen: return True; seen.add(n)，更直观但代码更长
