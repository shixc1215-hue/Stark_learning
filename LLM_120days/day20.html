🧩 知识点一：继承（Inheritance） ~25 min
核心思想：继承是面向对象三大特性之一，允许子类复用父类的属性和方法，并在其基础上扩展或覆盖（重写）。就像 AM C 不良资产分类体系 —— 金融不良资产 和 非金不良资产 都继承自 不良资产 这个基类，共享“债务人、本金、利率”等属性，同时各有自己的特殊属性。

1.1 基本语法：子类继承父类

class Parent:
    """父类（基类）：不良资产基类"""
    def __init__(self, debtor_name, principal, interest_rate):
        self.debtor_name = debtor_name    # 债务人名称
        self.principal = principal        # 本金（万元）
        self.interest_rate = interest_rate  # 利率（年化）

    def calc_total(self, years=1):
        """计算本息合计"""
        interest = self.principal * self.interest_rate / 100 * years
        return self.principal + interest

    def summary(self):
        return f"{self.debtor_name}: 本金{self.principal}万, 年化{self.interest_rate}%"


class Child(Parent):
    """子类（派生类）：金融不良资产"""
    def __init__(self, debtor_name, principal, interest_rate, bank):
        # super() 调用父类的 __init__，避免重复写属性赋值
        super().__init__(debtor_name, principal, interest_rate)
        self.bank = bank  # 子类独有的属性：贷款银行

    def summary(self):
        """方法重写（Override）：覆盖父类的 summary"""
        parent_info = super().summary()  # 也可以复用父类方法
        return f"[金融]{parent_info}, 来源:{self.bank}"


# 使用
asset = Child("某某置业", 50000, 4.35, "XX银行")
print(asset.calc_total(2))   # ✅ 继承了父类方法 → 54350.0
print(asset.summary())        # ✅ 子类重写版本 → [金融]某某置业: 本金50000万...
print(asset.bank)             # ✅ 子类独有属性 → XX银行
💡 super() 的本质：super().__init__(...) 不是“调用父类的构造函数”这么简单。它遵循 MRO（方法解析顺序） 链查找下一个类的方法，在多重继承时特别关键。单继承场景下可以简单理解为“调父类的同名方法”。

1.2 继承的类型检查：isinstance() 和 issubclass()

print(isinstance(asset, Child))     # True  — asset 是 Child 的实例
print(isinstance(asset, Parent))    # True  — 子类实例也是父类实例 ⭐
print(issubclass(Child, Parent))    # True  — Child 是 Parent 的子类

# 实际应用：统一接口处理不同类型的不良资产
def process_asset(asset):
    if not isinstance(asset, Parent):
        raise TypeError("只接受不良资产类型")
    print(f"处理: {asset.summary()}")

1.3 多重继承（了解即可）

# Python 支持多重继承，但建议谨慎使用
class JSONExportable:
    def to_json(self):
        import json
        return json.dumps(self.__dict__, ensure_ascii=False, default=str)

class CSVPrintable:
    def to_csv_row(self):
        return ",".join(str(v) for v in self.__dict__.values())

class FinanceAsset(Parent, JSONExportable, CSVPrintable):
    """金融资产：继承父类 + 两个 mixin 功能类"""
    pass

fa = FinanceAsset("某某公司", 30000, 3.85, "YY银行")
print(fa.to_json())    # ✅ 来自 JSONExportable
print(fa.to_csv_row()) # ✅ 来自 CSVPrintable
print(fa.summary())    # ✅ 来自 Parent
⚠️ 多重继承陷阱：多用 Mixin（混入） 模式（如上面 JSONExportable 不继承任何类），避免菱形继承问题。用 ClassName.__mro__ 可以查看方法解析顺序。
🔒 知识点二：封装（Encapsulation） ~20 min
核心思想：封装是通过访问控制来保护对象内部状态，防止外部代码随意修改导致数据不一致。就像 AMC 监管报表 — C 表中的“不良资产余额”不能被随便改成负数，必须经过校验。

2.1 Python 的三种访问级别

class BadLoanRecord:
    def __init__(self, loan_id, amount):
        self.loan_id = loan_id          # 公有属性：外部随便访问
        self._audit_flag = False        # 受保护（约定）：下划线开头，请勿直接改
        self.__amount = amount          # 私有属性：双下划线开头，会触发名称改写

    # 通过方法提供受控的读写
    def get_amount(self):
        return self.__amount

    def set_amount(self, value):
        if value < 0:
            raise ValueError("不良资产余额不能为负数")
        self.__amount = value
        self._audit_flag = True  # 修改后标记需要重新审计

    # 受保护方法：子类可以调用，但外部不建议直接调
    def _validate(self):
        return self.__amount > 0


record = BadLoanRecord("BL-2026-001", 1000)

print(record.loan_id)         # ✅ 公有：直接访问
print(record.get_amount())    # ✅ 通过方法访问私有属性

record.set_amount(800)        # ✅ 通过方法安全修改（内部会校验）
# record.__amount = -500      # ❌ 直接赋值无效（名称改写为 _BadLoanRecord__amount）
# record.set_amount(-500)     # ❌ 校验拦截，抛出 ValueError

# Python 的“私有”其实是名称改写（Name Mangling）
print(record._BadLoanRecord__amount)  # 理论上能访问，但千万别这么干
Python 风格

约定大于强制

Python 没有 Java 那样的 private 关键字，_ 和 __ 都是约定，不是真正的访问控制。

单下划线 _：“我是内部用的，外部别碰”

双下划线 __：“我真不想让你碰，已改名”

🎯 知识点三：@property 属性装饰器 ~20 min
核心思想：@property 让方法像属性一样访问，同时可以对赋值进行校验。这是 Python 实现 getter/setter 的优雅方式 — 代码从 obj.get_amount() / obj.set_amount(100) 变成 obj.amount / obj.amount = 100，外部调用者完全感知不到内部有校验逻辑。

3.1 基础用法：只读属性 + 带校验的赋值

class Loan:
    def __init__(self, loan_id, principal, overdue_days):
        self.loan_id = loan_id
        # 用内部属性（带下划线）存储实际值
        self._principal = principal
        self._overdue_days = overdue_days

    # --- 只读属性 ---
    @property
    def loan_id(self):
        """贷款编号（只读，外部不能修改）"""
        return self._loan_id

    @loan_id.setter
    def loan_id(self, value):
        self._loan_id = value  # 只在 __init__ 中设置一次

    # --- 带校验的属性 ---
    @property
    def principal(self):
        """本金金额（万元），不允许负值"""
        return self._principal

    @principal.setter
    def principal(self, value):
        if value <= 0:
            raise ValueError(f"本金必须大于0，当前值: {value}")
        if value > 1000000:
            raise ValueError("单笔本金不能超过100亿")
        self._principal = value

    # --- 计算属性（派生值，不存储） ---
    @property
    def overdue_months(self):
        """逾期天数 → 逾期月数（向上取整）"""
        import math
        return math.ceil(self._overdue_days / 30)

    # --- 只读的计算属性（无 setter） ---
    @property
    def risk_level(self):
        """根据逾期月数自动判定风险等级"""
        if self.overdue_months <= 3:
            return "关注"
        elif self.overdue_months <= 12:
            return "次级"
        elif self.overdue_months <= 36:
            return "可疑"
        else:
            return "损失"


# 使用
loan = Loan("BL-001", 50000, 120)
print(loan.principal)        # ✅ 像属性一样读取 → 50000
print(loan.overdue_months)   # ✅ 计算属性 → 4
print(loan.risk_level)       # ✅ 自动判定 → "次级"

loan.principal = 48000       # ✅ 正常赋值（内部自动校验）
# loan.principal = -100      # ❌ ValueError: 本金必须大于0
# loan.risk_level = "低风险" # ❌ AttributeError: 只读属性没有 setter
💡 @property 的使用时机判断：
• 如果只是简单读写，用公有属性就好
• 如果需要校验、转换、或计算派生值，用 @property
• 不要过度使用 — 每个属性都加 property 会增加代码复杂度

3.2 结合 @property 的缓存模式（lru_cache）

from functools import lru_cache

class AssetAnalyzer:
    def __init__(self, assets):
        self._assets = assets  # 列表，每项是一个字典

    @property
    @lru_cache(maxsize=1)
    def total_amount(self):
        """总金额：首次计算后缓存，数据不变时不再重复计算"""
        print("  [DEBUG] 正在计算总金额...")  # 只会在第一次打印
        return sum(a.get("principal", 0) for a in self._assets)

    def invalidate_cache(self):
        """数据变化后清除缓存"""
        self.total_amount.fget.cache_clear()

analyzer = AssetAnalyzer([{"principal": 1000}, {"principal": 2000}])
print(analyzer.total_amount)  # 触发计算并缓存
print(analyzer.total_amount)  # 直接读缓存，不再打印 DEBUG

analyzer._assets.append({"principal": 500})
analyzer.invalidate_cache()  # 清缓存
print(analyzer.total_amount)  # 重新计算 → 3500

为什么要这么设计？

未来接入不同 LLM 厂商时，只需新增子类（如 ZhipuChatBot、OpenAIChatBot），不用改业务代码。

4.1 父类：BaseChatBot

class BaseChatBot:
    """通用 LLM ChatBot 基类
    封装了 API 调用、历史管理、配置等通用逻辑
    子类只需关注：系统提示词 + 业务方法
    """

    def __init__(self, api_key, model="glm-4-flash", base_url=None):
        # --- 用私有属性保护敏感配置 ---
        self._api_key = api_key
        self._model = model
        self._base_url = base_url or "https://open.bigmodel.cn/api/paas/v4"

        # --- 历史记录 ---
        self._history = []
        self._max_history = 50  # 最大保留轮数

        # --- 子类需要设置的属性 ---
        self._system_prompt = ""

    # --- @property：只读访问配置 ---
    @property
    def model(self):
        return self._model

    @property
    def message_count(self):
        """当前历史消息数"""
        return len(self._history)

    # --- 通用 LLM 调用方法（子类可重写） ---
    def _call_llm(self, messages):
        """调用 LLM API 的核心方法（可被子类重写以适配不同厂商）"""
        try:
            from openai import OpenAI
            client = OpenAI(
                api_key=self._api_key,
                base_url=self._base_url
            )
            response = client.chat.completions.create(
                model=self._model,
                messages=messages,
                temperature=0.7,
                max_tokens=1024
            )
            return response.choices[0].message.content
        except Exception as e:
            return f"[API 调用失败] {type(e).__name__}: {e}"

    def send_message(self, user_input):
        """发送消息并获取回复（完整流程）"""
        self._history.append({"role": "user", "content": user_input})

        # 构造完整消息列表
        messages = []
        if self._system_prompt:
            messages.append({"role": "system", "content": self._system_prompt})
        messages.extend(self._history)

        # 调用 LLM
        reply = self._call_llm(messages)

        # 记录回复
        self._history.append({"role": "assistant", "content": reply})

        # 控制历史长度
        if len(self._history) > self._max_history * 2:
            self._history = self._history[-self._max_history * 2:]

        return reply

    def clear_history(self):
        self._history.clear()

    def export_history(self):
        """导出对话记录"""
        import json
        return json.dumps(self._history, ensure_ascii=False, indent=2)

4.2 子类：AMCChatBot（业务特化）

class AMCChatBot(BaseChatBot):
    """AMC 不良资产管理专用 ChatBot
    继承 BaseChatBot，添加 AMC 业务提示词和专用方法
    """

    def __init__(self, api_key, model="glm-4-flash"):
        # 调用父类 __init__
        super().__init__(api_key=api_key, model=model)

        # 设置 AMC 专用系统提示词
        self._system_prompt = """你是AMC（资产管理公司）的不良资产分析专家。
你的职责是帮助分析不良资产数据、解释监管报表、提供催收建议。
回答时请注意：
1. 术语准确，符合银保监会规范
2. 数据敏感信息需脱敏处理
3. 引用监管文件时注明文号
4. 不确定的问题明确标注"待核实"
"""

    # --- AMC 业务方法 ---
    def query_asset(self, query_text):
        """资产查询快捷方法"""
        prompt = f"请根据以下查询分析不良资产情况：{query_text}"
        return self.send_message(prompt)

    def risk_assess(self, debtor_info):
        """风险评估快捷方法"""
        prompt = f"请对以下债务人的风险等级进行评估：\n{debtor_info}"
        return self.send_message(prompt)

    def explain_report(self, report_type, content):
        """解释监管报表"""
        prompt = f"请解释 {report_type} 监管报表中的以下内容：\n{content}"
        return self.send_message(prompt)

    # --- @property：计算 AMC 相关统计 ---
    @property
    def is_amc_bot(self):
        """标识这是 AMC 专用 Bot"""
        return True

    @property
    def business_domain(self):
        return "不良资产管理"

🧠 LeetCode 每日一题： #278 - 第一个错误版本

你有一个产品经理和一个 API isBadVersion(version) 返回 bool。找出第一个错误版本（之后全部是错误的）。尽量减少调用次数。

class Solution:
    def firstBadVersion(self, n: int) -> int:
        left, right = 1, n
        while left < right:
            mid = (left + right) // 2
            if isBadVersion(mid):
                right = mid      # mid 可能就是第一个，不能跳过
            else:
                left = mid + 1   # mid 及之前都正确，从 mid+1 开始找
        return left              # left == right，就是答案

# 💡 经典二分查找：O(log n) 时间复杂度
# AMC类比：在一批按日期排列的不良资产中，找到第一笔违约的

🎯 面向对象设计核心原则：
• 单一职责：一个类只做一件事（BaseChatBot 管通信，AMCChatBot 管业务）
• 开闭原则：对扩展开放（新增子类），对修改封闭（不改父类）
