🤔为什么要学面向对象？5 min

过去 18 天你写的 Python 代码，都是"面向过程"的——写函数、调函数，一步一步来。这种方式在写脚本、做数据分析时完全够用。但现在，你要开始构建真正的 LLM 应用，情况变了：

❌ 面向过程写法

你的代码里散落着大量变量和函数：

api_key = "xxx"
base_url = "https://..."
model_name = "glm-4-flash"
history = []

def chat(question):
    # 20行代码...
    pass

def save_log(msg):
    # 10行代码...
    pass

10个全局变量、8个散落的函数……项目一大就乱套。

✅ 面向对象写法

所有相关的东西"打包"到一个类里：

class AMCChatBot:
    def __init__(self, api_key, model):
        self.api_key = api_key
        self.model = model
        self.history = []

    def chat(self, question):
        # 20行代码...
        pass

    def save_log(self, msg):
        # 10行代码...
        pass

数据+行为绑定在一起，清晰、可复用、可扩展。

核心思想：面向对象 = 把数据和操作数据的方法打包在一起，形成"对象"。就像数仓里的"表"——字段（数据）+ SQL查询（方法）绑定在一起，而不是散落各处。

OOP 的三个关键概念

概念数仓类比Python 中的体现
类 (Class)表的 Schema 定义（建表 DDL）class AMCChatBot:
对象 (Object)表里的具体一张表实例bot = AMCChatBot(...)
方法 (Method)对表执行的操作（INSERT/SELECT）bot.chat("你好")

类是对象的"蓝图"。用 class 关键字定义，用 __init__（初始化方法）设置对象的初始状态。

2.1 最简单的类

# ===== 定义一个类 =====
class NPLReport:
    """AMC监管报送C表——这是一个空类"""
    pass

# ===== 从类创建对象（实例化） =====
report_a = NPLReport()    # 创建了第一个对象
report_b = NPLReport()    # 创建了第二个对象

print(type(report_a))     # <class '__main__.NPLReport'>

💡 类命名规范：Python 类名用大驼峰（CamelCase），每个单词首字母大写：AMCChatBot、DataLoader。这和函数名的 snake_case 不同。

2.2 __init__：构造函数（初始化方法）

class NPLReport:
    """不良资产C表数据模型"""

    # __init__ 在创建对象时自动调用
    # self 代表"当前正在创建的这个对象"
    def __init__(self, report_id, report_date, org_code):
        self.report_id = report_id       # 实例属性：报送编号
        self.report_date = report_date   # 实例属性：报送日期
        self.org_code = org_code         # 实例属性：机构代码
        self.status = "draft"           # 实例属性：默认状态为草稿
        self.records = []                # 实例属性：空的数据记录列表


# ===== 使用 =====
rpt = NPLReport(
    report_id="C-2026-001",
    report_date="2026-06-30",
    org_code="ORG001"
)

print(rpt.report_id)     # C-2026-001
print(rpt.status)        # draft
print(rpt.records)       # []
self 是什么？
self 是 Python 自动传入的参数，指向当前对象自己。你可以理解为"这个对象自己"。在 __init__ 里 self.report_id = report_id 就是"把传入的 report_id 值存到这个对象自己的 report_id 属性上"。
⚠️ 常见错误：在 __init__ 里忘了写 self.：report_id = report_id（没有 self）只会创建一个局部变量，对象创建完就丢了！

3.1 实例方法

方法就是定义在类里的函数，第一个参数永远是 self，可以通过 self 访问对象的属性：

class NPLReport:
    def __init__(self, report_id, report_date, org_code):
        self.report_id = report_id
        self.report_date = report_date
        self.org_code = org_code
        self.records = []
        self.status = "draft"

    # ===== 实例方法：添加一条记录 =====
    def add_record(self, debtor_name, principal, category):
        """向C表添加一条不良资产记录"""
        record = {
            "debtor_name": debtor_name,   # 债务人名称
            "principal": principal,         # 本金金额
            "category": category,            # 不良分类(次级/可疑/损失)
            "status": "pending"              # 待审核
        }
        self.records.append(record)
        print(f"✅ 已添加记录：{debtor_name}，本金 {principal} 万元")

    # ===== 实例方法：统计总金额 =====
    def total_principal(self):
        """计算所有记录的本金总和"""
        return sum(r["principal"] for r in self.records)

    # ===== 实例方法：生成校验摘要 =====
    def summary(self):
        """生成报送校验摘要"""
        count = len(self.records)
        total = self.total_principal()
        return (f"报送 {self.report_id} | 日期 {self.report_date}\n"
                f"记录数：{count}，本金合计：{total:.2f} 万元")


# ===== 使用 =====
rpt = NPLReport("C-2026-001", "2026-06-30", "ORG001")

# 通过方法操作数据，而不是直接修改属性
rpt.add_record("XX贸易有限公司", 1500.00, "次级")
rpt.add_record("YY房地产集团", 8200.50, "可疑")
rpt.add_record("ZZ制造有限公司", 320.00, "损失")

print(rpt.total_principal())   # 10020.5
print(rpt.summary())
# 报送 C-2026-001 | 日期 2026-06-30
# 记录数：3，本金合计：10020.50 万元

3.2 __str__：自定义打印格式

直接 print(对象) 会输出类似 <__main__.NPLReport object at 0x...> 的无意义内容。重写 __str__ 可以定义"打印时显示什么"：

class NPLReport:
    # ...（前面的 __init__ 和其他方法保持不变）...

    def __str__(self):
        """定义 print(对象) 时显示的内容"""
        return (f"NPLReport(id={self.report_id}, "
                f"date={self.report_date}, "
                f"records={len(self.records)})")

# ===== 使用 =====
rpt = NPLReport("C-2026-001", "2026-06-30", "ORG001")
rpt.add_record("XX贸易有限公司", 1500.00, "次级")
print(rpt)   # NPLReport(id=C-2026-001, date=2026-06-30, records=1)
💡 __str__ vs __repr__：
__str__ 是给"人"看的（友好格式），__repr__ 是给"开发者"看的（调试用）。日常开发先实现 __str__ 就够了。

3.3 方法内调用方法

class NPLReport:
    # ...（__init__、add_record 不变）...

    def total_principal(self):
        return sum(r["principal"] for r in self.records)

    def average_principal(self):
        """平均每条记录的本金"""
        if not self.records:
            return 0
        return self.total_principal() / len(self.records)  # 方法内调用另一个方法

    def validate(self):
        """校验规则：单条记录本金不能超过 10000 万元"""
        errors = []
        for r in self.records:
            if r["principal"] > 10000:
                errors.append(f"⚠️ {r['debtor_name']} 本金超限：{r['principal']} 万")
        # 也可以调用自己的 summary() 方法
        print(self.summary())
        if errors:
            print("校验结果：❌ 不通过")
            for e in errors:
                print(f"  {e}")
        else:
            print("校验结果：✅ 通过")
        return len(errors) == 0
🤖LLM 实战：封装 AMCChatBot 类25 min

现在用面向对象的方式，把前 18 天学的 LLM API 调用、对话记录管理、Prompt Engineering 全部封装到一个类里。这将是你后续构建完整 ChatBot 和 Agent 的基石。

from openai import OpenAI
import json
from datetime import datetime


class AMCChatBot:
    """AMC 智能问答助手——封装 LLM API 调用的类"""

    # ===== 类属性（所有对象共享） =====
    DEFAULT_SYSTEM_PROMPT = """你是一名AMC（资产管理公司）数据分析助手。
你的职责是回答关于不良资产管理、监管报送、回收率分析等问题。
回答时请结合 AMC 业务场景，使用专业但易懂的语言。
如果不确定答案，请明确说明。"""

    def __init__(self, api_key, base_url=None, model="glm-4-flash"):
        """
        初始化 ChatBot
        - api_key: API 密钥
        - base_url: API 地址（默认智谱）
        - model: 模型名称
        """
        self.api_key = api_key
        self.base_url = base_url or "https://open.bigmodel.cn/api/paas/v4/"
        self.model = model
        self.client = OpenAI(
            api_key=api_key,
            base_url=self.base_url
        )
        self.system_prompt = self.DEFAULT_SYSTEM_PROMPT
        self.history = []          # 对话历史
        self.log = []              # 操作日志
        self.created_at = datetime.now()

    def chat(self, user_input, temperature=0.7, max_tokens=1024):
        """
        发送消息并获取回复
        - user_input: 用户输入的问题
        - temperature: 创造性（0-1，越高越有创意）
        - max_tokens: 最大返回 token 数
        返回：LLM 的回复文本
        """
        # 1. 构建消息列表
        messages = [{"role": "system", "content": self.system_prompt}]
        messages.extend(self.history)  # 加入历史对话
        messages.append({"role": "user", "content": user_input})

        # 2. 调用 API（带异常处理）
        try:
            response = self.client.chat.completions.create(
                model=self.model,
                messages=messages,
                temperature=temperature,
                max_tokens=max_tokens
            )

            # 3. 提取回复内容
            reply = response.choices[0].message.content

            # 4. 更新对话历史
            self.history.append({"role": "user", "content": user_input})
            self.history.append({"role": "assistant", "content": reply})

            # 5. 记录日志
            self._log(user_input, reply)

            return reply

        except Exception as e:
            error_msg = f"API 调用失败：{type(e).__name__}: {e}"
            self.log.append({"time": datetime.now(), "error": error_msg})
            return f"❌ {error_msg}"

    def _log(self, question, answer):
        """内部方法（以 _ 开头）：记录日志"""
        self.log.append({
            "time": datetime.now(),
            "question": question[:50] + ("..." if len(question) > 50 else ""),
            "answer_len": len(answer)
        })

    def clear_history(self):
        """清空对话历史"""
        self.history = []
        print("🧹 对话历史已清空")

    def export_history(self, filepath):
        """将对话历史导出为 JSON 文件"""
        data = {
            "export_time": str(datetime.now()),
            "model": self.model,
            "history": self.history
        }
        with open(filepath, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        print(f"💾 对话历史已导出到：{filepath}")

    def show_stats(self):
        """显示统计信息"""
        rounds = len(self.history) // 2
        print(f"📊 Bot 统计：")
        print(f"   模型：{self.model}")
        print(f"   对话轮数：{rounds}")
        print(f"   创建时间：{self.created_at.strftime('%Y-%m-%d %H:%M')}")
        print(f"   日志条数：{len(self.log)}")

    def __str__(self):
        return f"AMCChatBot(model={self.model}, rounds={len(self.history)//2})"
代码结构解读：
① DEFAULT_SYSTEM_PROMPT 是类属性，所有 AMCChatBot 对象共享同一个默认 prompt
② __init__ 里用 self.xxx = xxx 设置实例属性，每个对象有自己的 API Key、模型、历史记录
③ chat() 是核心方法，封装了完整的"发请求→拿回复→更新历史→记录日志"流程
④ _log() 以 _ 开头，表示"内部方法"，外部不直接调用
⑤ export_history() 把对话存为 JSON 文件——复用了 Day 6 学的文件读写

特性类属性实例属性

🏢综合练习：用类建模 AMC 报送校验器10 min

结合你在 AMC 的监管报送经验，用类来封装一个"C表数据校验器"：

class CTableValidator:
    """C表监管报送数据校验器"""

    def __init__(self, report_id):
        self.report_id = report_id
        self.rules = []      # 校验规则列表
        self.results = []    # 校验结果列表
        self.passed = True

    def add_rule(self, rule_name, check_fn, error_msg):
        """
        添加一条校验规则
        - rule_name: 规则名称
        - check_fn: 校验函数（接收 records，返回 True/False）
        - error_msg: 不通过时的提示信息
        """
        self.rules.append({
            "name": rule_name,
            "check": check_fn,
            "error_msg": error_msg
        })

    def validate(self, records):
        """对数据记录执行全部校验规则"""
        self.results = []
        self.passed = True

        for rule in self.rules:
            is_ok = rule["check"](records)
            self.results.append({
                "rule": rule["name"],
                "passed": is_ok,
                "message": "" if is_ok else rule["error_msg"]
            })
            if not is_ok:
                self.passed = False

        return self.passed

    def report(self):
        """生成校验报告"""
        total = len(self.results)
        failed = sum(1 for r in self.results if not r["passed"])
        status = "✅ 全部通过" if self.passed else f"❌ {failed}/{total} 条不通过"

        print(f"{'='*40}")
        print(f"校验报告 | {self.report_id} | {status}")
        print(f"{'='*40}")
        for r in self.results:
            icon = "✅" if r["passed"] else "❌"
            msg = r["message"] if r["message"] else "通过"
            print(f"  {icon} {r['rule']}: {msg}")
        print(f"{'='*40}")


# ===== 使用校验器 =====
records = [
    {"debtor": "公司A", "principal": 5000, "category": "次级", "days_overdue": 180},
    {"debtor": "公司B", "principal": 15000, "category": "可疑", "days_overdue": 720},
    {"debtor": "公司C", "principal": -200, "category": "损失", "days_overdue": 1000},
    {"debtor": "", "principal": 800, "category": "次级", "days_overdue": 90},
]

validator = CTableValidator("C-2026-001")

# 添加校验规则（用 lambda 定义检查逻辑）
validator.add_rule(
    "本金非负校验",
    lambda recs: all(r["principal"] >= 0 for r in recs),
    "存在本金为负值的记录"
)
validator.add_rule(
    "债务人非空校验",
    lambda recs: all(r["debtor"].strip() != "" for r in recs),
    "存在债务人名称为空的记录"
)
validator.add_rule(
    "五级分类合法性",
    lambda recs: all(r["category"] in ["正常","关注","次级","可疑","损失"] for r in recs),
    "存在不合法的五级分类值"
)
validator.add_rule(
    "单笔上限校验(1亿)",
    lambda recs: all(r["principal"] <= 100000 for r in recs),
    "存在单笔本金超过1亿元的记录"
)

# 执行校验
validator.validate(records)
validator.report()

# 输出：
# ========================================
# 校验报告 | C-2026-001 | ❌ 2/4 条不通过
# ========================================
#   ✅ 五级分类合法性: 通过
#   ✅ 单笔上限校验(1亿): 通过
#   ❌ 本金非负校验: 存在本金为负值的记录
#   ❌ 债务人非空校验: 存在债务人名称为空的记录
# ========================================
💡 设计亮点：
① add_rule 接收函数作为参数——这是"高阶函数"的应用（Day 8 学的 map/filter 就是高阶函数）
② 规则和校验器解耦：可以随时增减规则，不用修改校验逻辑
③ 你在 AMC 写的 SQL 校验规则，未来都可以迁移成这样的 Python 校验器！

题目：找不同

给定两个字符串 s 和 t，t 是 s 随机打乱后加了一个字母。找出被添加的字母。

示例：s = "abcd", t = "abcde" → 返回 "e"

进阶要求：尝试用 面向对象 的方式封装一个 DifferenceFinder 类，支持以下方法：find_diff(s, t)、find_diff_v2(s, t)（不同解法）。

思路提示：

  • 解法1（ASCII求和）：两个字符串的 ASCII 码之和相减，差值就是多出的字母
  • 解法2（Counter计数）：用 collections.Counter 统计字符频次，找差值
  • 解法3（位运算XOR）：所有字符异或，相同的抵消，剩下的就是答案

先自己尝试写，再对照下面的参考答案：

from collections import Counter


class DifferenceFinder:
    """字符串差异查找器"""

    @staticmethod
    def find_diff_sum(s, t):
        """解法1：ASCII 求和法 —— O(n) 时间 O(1) 空间"""
        # sum() 对字符串求 ASCII 码之和
        diff = sum(ord(c) for c in t) - sum(ord(c) for c in s)
        return chr(diff)

    @staticmethod
    def find_diff_counter(s, t):
        """解法2：Counter 计数法 —— O(n) 时间 O(n) 空间"""
        count_s = Counter(s)
        count_t = Counter(t)
        # 做差集：t 中有但 s 中没有的字符
        diff = count_t - count_s
        return list(diff.keys())[0]

    @staticmethod
    def find_diff_xor(s, t):
        """解法3：异或法 —— O(n) 时间 O(1) 空间"""
        result = 0
        for c in s + t:
            result ^= ord(c)
        return chr(result)


# ===== 测试 =====
finder = DifferenceFinder()
s, t = "abcd", "abcde"
print(finder.find_diff_sum(s, t))       # e
print(finder.find_diff_counter(s, t))    # e
print(finder.find_diff_xor(s, t))       # e

# 复杂测试
s2, t2 = "", "y"
print(finder.find_diff_sum(s2, t2))      # y
print(finder.find_diff_xor(s2, t2))     # y
@staticmethod 是什么？
这是 Python 的"静态方法"装饰器。加了它之后，方法不需要 self 参数，也不需要创建对象就能调用：DifferenceFinder.find_diff_sum(s, t)。当方法不需要访问实例属性时，用 @staticmethod 更合理。
