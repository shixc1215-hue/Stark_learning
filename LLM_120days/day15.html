🐍 Python 路径操作：os 模块 vs pathlib ~45min
💡 为什么要专门学路径操作？
昨天我们学了模块和包的 import，今天学的路径操作是它的延伸 —— 你需要告诉程序文件在哪里。在 LLM 应用中，你要加载文档、保存对话记录、管理知识库文件，全都需要操作文件路径。这是自动化处理的基础能力。

1.1 os 模块 —— 传统方式（了解即可，能读别人代码）

os 和 os.path 是 Python 最老牌的路径操作方式。虽然现在推荐用 pathlib，但你在工作中看到老代码时一定要能读懂。

常用 os.path 函数速查

函数作用示例
os.path.join(a, b)拼接路径（自动处理 / 和 \）join("data", "amc.csv") → "data/amc.csv"
os.path.exists(path)路径是否存在exists("data/amc.csv") → True/False
os.path.isfile(path)是否是文件isfile("data/amc.csv") → True
os.path.isdir(path)是否是目录isdir("data") → True
os.listdir(path)列出目录下所有文件/文件夹listdir("data") → ['a.csv', 'b.txt']
os.path.basename(path)取文件名basename("data/amc.csv") → "amc.csv"
os.path.dirname(path)取目录部分dirname("data/amc.csv") → "data"
os.makedirs(path)递归创建目录makedirs("output/2026/06") 创建多层目录
import os

# ===== 拼接路径（核心！永远用 os.path.join，不要手动写 /） =====
data_dir = os.path.join("data", "amc", "contracts")
print(data_dir)
# 输出: data/amc/contracts（Windows 上会自动用 \）

# ===== 检查路径 =====
csv_path = os.path.join(data_dir, "report.csv")
print(os.path.exists(csv_path))      # 文件在不在？
print(os.path.isfile(csv_path))      # 是文件吗？
print(os.path.isdir(data_dir))       # 是文件夹吗？

# ===== 遍历目录 =====
for filename in os.listdir("data"):
    full_path = os.path.join("data", filename)  # 重要：要拼接完整路径
    if os.path.isfile(full_path):
        print(f"  文件: {filename}")
    else:
        print(f"  目录: {filename}")

# ===== 创建目录 =====
os.makedirs("output/charts", exist_ok=True)
# exist_ok=True 表示"目录已存在也不报错"，非常实用！
⚠️ 常见坑：
永远不要手动拼接路径字符串！"data/" + "file.txt" 在 Windows 上会出问题（Windows 用反斜杠 \）。用 os.path.join() 自动适配当前操作系统。

也不要手动写 \ —— Python 中 \ 是转义字符，"data\new" 会被解释成 data + 换行符 + ew。用 os.path.join() 或 r 前缀原始字符串 r"data\new"。

1.2 pathlib —— 现代方式（✅ 重点掌握，自己写代码用它）

pathlib 是 Python 3.4 引入的，用面向对象的方式操作路径。比 os 模块更直观、更安全。以后写代码优先用 pathlib。

🎯 核心思路：pathlib 把路径变成一个对象（Path），用 / 符号拼接路径（像数学除法一样自然），路径对象的每个部分都可以直接访问。 
from pathlib import Path

# ===== 创建路径对象 =====
# 当前目录下的 data/amc 文件夹
data_dir = Path("data") / "amc"      # 用 / 拼接！比 os.path.join() 直观多了
print(data_dir)
# 输出: data\amc（Windows）或 data/amc（Linux/Mac）

# ===== 检查路径 =====
data_dir.exists()       # 是否存在？
data_dir.is_file()      # 是文件？
data_dir.is_dir()       # 是目录？

# ===== 获取路径的各个部分 =====
p = Path("data/amc/contracts/report_2026.csv")
p.name          # "report_2026.csv" — 文件名（含后缀）
p.stem          # "report_2026" — 文件名（不含后缀）
p.suffix        # ".csv" — 后缀名
p.parent        # "data/amc/contracts" — 父目录
p.parents[0]    # 同 parent
p.parents[1]    # "data/amc" — 上上级目录

# ===== 创建目录 =====
data_dir.mkdir(parents=True, exist_ok=True)
# parents=True = 自动创建所有缺失的父目录
# exist_ok=True = 已存在不报错

# ===== 遍历文件（比 os.listdir 更强大） =====
# 列出目录下所有 .csv 文件
for csv_file in Path("data").glob("*.csv"):
    print(csv_file)    # 输出: data\report1.csv, data\report2.csv ...

# 递归查找（包括子文件夹里的 .csv）
for csv_file in Path("data").glob("**/*.csv"):
    print(csv_file)    # 输出: data\sub\deep\file.csv 也能找到！

# ===== 读写文件（Path 对象自带方法！） =====
config = Path("config.json")
content = config.read_text(encoding="utf-8")   # 读取文本
config.write_text('{"key": "value"}', encoding="utf-8")  # 写入文本
💡 pathlib vs os.path 对比记忆
记住一个公式：Path("a") / "b" / "c" 就等于 os.path.join("a", "b", "c")。pathlib 用斜杠拼路径，更直观。

在 LLM 项目中，管理文档知识库时 pathlib 特别好用 —— Path("knowledge_base").glob("**/*.pdf") 一行代码就能找到所有 PDF 文档。

🐍 Python 日期时间处理：datetime ~15min
💡 为什么要学 datetime？
在数据处理和 LLM 应用中，日期无处不在 —— AMC 项目的收购日期、报告生成时间、日志时间戳。你需要创建日期、计算日期差（某项目逾期了多少天）、格式化输出（"2026年06月08日"）。 
from datetime import datetime, date, timedelta

# ===== 获取当前时间 =====
now = datetime.now()          # 2026-06-08 09:45:58.123456
today = date.today()          # 2026-06-08

print(now.year)               # 2026
print(now.month)              # 6
print(now.day)                # 8
print(now.hour)               # 9

# ===== 创建指定日期 =====
# AMC 项目收购日期
acquire_date = date(2024, 3, 15)   # 2024年3月15日
print(acquire_date)                # 2024-03-15

# ===== 日期差计算（timedelta）=====
# 计算项目持有天数
days_held = today - acquire_date
print(f"项目已持有 {days_held.days} 天")   # 项目已持有 820 天

# 往前/往后推 N 天
deadline = today + timedelta(days=30)    # 30天后
last_week = today - timedelta(days=7)    # 7天前
print(f"处置截止日: {deadline}")          # 处置截止日: 2026-07-08

# ===== 日期转字符串（strftime —— format） =====
# 常用格式化符号：
# %Y=四位数年  %m=两位数月  %d=两位数日
# %H=时  %M=分  %S=秒
now_str = now.strftime("%Y-%m-%d %H:%M:%S")
print(now_str)                    # 2026-06-08 09:45:58

cn_str = now.strftime("%Y年%m月%d日")
print(cn_str)                     # 2026年06月08日

# 文件命名常用格式
file_str = now.strftime("%Y%m%d_%H%M%S")
print(file_str)                   # 20260608_094558
filename = f"report_{file_str}.csv"
# → report_20260608_094558.csv

# ===== 字符串转日期（strptime —— parse） =====
raw = "2024-03-15"
parsed = datetime.strptime(raw, "%Y-%m-%d")
print(parsed)                     # 2024-03-15 00:00:00
print(type(parsed))               # <class 'datetime.datetime'>

# ===== 判断日期先后 =====
if acquire_date < today:
    print("收购日已过去")
if deadline > today:
    remaining = (deadline - today).days
    print(f"距截止日还有 {remaining} 天")
💡 strftime vs strptime 记忆技巧
strftime = String Format Time = 日期 → 字符串（f = format）
strptime = String Parse Time = 字符串 → 日期（p = parse）

在 AMC 场景中：用 datetime 计算逾期天数、生成报告文件名、记录日志时间戳 —— 这三个操作是最常用的。
🛠️ 综合练习：文件整理脚本 ~15min

用今天学的 pathlib + datetime，写一个按日期整理文件的小脚本。这会出现在你未来的 LLM 项目中 —— 自动管理生成的文档。

from pathlib import Path
from datetime import datetime

def organize_by_date(source_dir: str, target_dir: str):
    """
    把 source_dir 中的文件按最后修改日期整理到 target_dir 的子文件夹中
    子文件夹命名格式: YYYY-MM
    """
    source = Path(source_dir)
    target = Path(target_dir)
    target.mkdir(parents=True, exist_ok=True)

    for filepath in source.iterdir():
        if not filepath.is_file():    # 跳过文件夹
            continue

        # 获取文件修改时间并格式化为 YYYY-MM
        mtime = datetime.fromtimestamp(filepath.stat().st_mtime)
        folder_name = mtime.strftime("%Y-%m")
        dest_folder = target / folder_name
        dest_folder.mkdir(exist_ok=True)

        # 移动文件到目标文件夹
        dest_file = dest_folder / filepath.name
        filepath.rename(dest_file)
        print(f"  {filepath.name} → {folder_name}/{filepath.name}")

    print(f"整理完成！共处理文件到: {target}")

# 使用示例
# organize_by_date("downloads", "organized")
# downloads/
#   ├── report1.csv  (修改于 2026-03-15)
#   ├── photo.jpg    (修改于 2026-03-15)
#   └── notes.txt    (修改于 2026-04-20)
# 整理后:
# organized/
#   ├── 2026-03/
#   │   ├── report1.csv
#   │   └── photo.jpg
#   └── 2026-04/
#       └── notes.txt

2. 用 filepath.stat().st_mtime 判断文档是否需要更新

🤖 LangChain 文档加载器实战 ~1.5h
💡 什么是文档加载器？为什么重要？
在 RAG 系统中，第一步就是把文档加载进来。LangChain 的文档加载器能读取各种格式的文件（.txt、.md、.pdf、.csv、网页等），统一转换成 Document 对象。

每个 Document 对象包含两部分：
- page_content：文档的文本内容
- metadata：元数据（来源路径、页码、创建时间等）

这是 RAG 系统的第一步，后面还要做"分块→向量化→检索→生成"，今天的重点是加载。

from langchain_community.document_loaders import DirectoryLoader, TextLoader

# 批量加载 data 文件夹下所有 .md 文件
loader = DirectoryLoader(
    path="data",
    glob="**/*.md",         # 匹配模式：所有子文件夹中的 .md 文件
    loader_cls=TextLoader,
    loader_kwargs={"encoding": "utf-8"}

all_docs = loader.load()
print(f"共加载 {len(all_docs)} 个文档")

for i, doc in enumerate(all_docs):

配合昨天学的 LangChain Chain 使用

把加载的文档和 LLM 调用串起来 —— 这就是 RAG 的雏形！

from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

# 1. 加载文档（今天学的）
loader = TextLoader("data/amc_knowledge.md", encoding="utf-8")
doc = loader.load()[0]

# 2. 截取前 1500 字符作为上下文（避免 token 超限）
context = doc.page_content[:1500]

# 3. 构建 Chain（昨天学的）
prompt = ChatPromptTemplate.from_template("""
你是AMC不良资产处置领域的专家。请根据以下参考资料回答用户问题。
如果资料中没有相关内容，请明确告知。

参考资料：
{context}

用户问题：{question}
请用简洁的中文回答：
""")

llm = ChatOpenAI(
    model="glm-4-flash",
    api_key="你的智谱API Key",
    base_url="https://open.bigmodel.cn/api/paas/v4"
)

chain = prompt | llm | StrOutputParser()

# 4. 提问
question = input("请输入问题（如"净回收率怎么算"）: ")
answer = chain.invoke({"context": context, "question": question})
print(f"\n回答: {answer}")
💡 这就是最简单的 RAG！
虽然我们还没有用向量数据库和 Embedding（那是 Phase 2 的内容），但你已经做了一个简化版的 RAG：

加载文档 → 截取内容 → 放进 Prompt → 调用 LLM

后面我们会把"截取内容"这一步替换成"向量化+语义检索"，效果会精确很多。

🎯 Hugging Face 是什么？
Hugging Face 是 AI 领域的"GitHub + npm + PyPI"综合体。它是最大的开源模型和工具社区，几乎所有主流开源模型都能在上面找到。

你在 Phase 0 注册了 HF 账号，今天来了解它的三大核心组件：

三大核心组件

📚 Model Hub（模型库）

做什么：存储和分享开源模型

类比：就像 GitHub 存代码，Model Hub 存模型

热门模型：
- Qwen2.5（通义千问）
- Llama 3（Meta）
- GLM-4（智谱）
- BGE（Embedding 模型）

📊 Datasets（数据集库）

做什么：存储和分享训练/微调数据集

类比：就像数据科学版的 Kaggle

常用场景：
- 下载对话数据集做微调
- 查看评测基准数据集
- 分享你自己的 AMC 领域数据

🛠️ Transformers 库（核心工具包）

做什么：统一的 API 来加载、运行任何开源模型

核心代码（概念了解即可）： 

from transformers import AutoModel, AutoTokenizer

# 一行代码加载任何模型
tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-7B")
model = AutoModel.from_pretrained("Qwen/Qwen2.5-7B")

# 编码文本 → 得到向量（就是 Embedding！）
inputs = tokenizer("不良资产净回收率", return_tensors="pt")
outputs = model(**inputs)

什么时候会用到？：Phase 3 微调时（PEFT 库基于 Transformers），以及直接加载开源 Embedding 模型做 RAG。

📚 今日题目：LeetCode #283 移动零

难度：简单  |  标签：数组、双指针

题目：给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

示例：[0,1,0,3,12] → [1,3,12,0,0]

要求：原地操作，不能使用额外数组。

思路提示

用一个指针（变量）记录"下一个非零元素应该放的位置"。遍历数组，遇到非零数就放到指针位置，指针前进。最后把剩余位置都填 0。 

def moveZeroes(nums):
    """
    双指针思路：
    - slow 指针：下一个非零元素应该放的位置
    - fast 指针：遍历数组的当前位置
    """
    slow = 0  # 慢指针：非零元素的"放置位"

    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow] = nums[fast]  # 把非零数移到前面
            slow += 1                # 放置位后移

    # slow 之后的位置全部填 0
    for i in range(slow, len(nums)):
        nums[i] = 0

    return nums

# 测试
print(moveZeroes([0, 1, 0, 3, 12]))       # [1, 3, 12, 0, 0]
print(moveZeroes([0, 0, 0, 1]))            # [1, 0, 0, 0]
print(moveZeroes([1, 2, 3]))               # [1, 2, 3]
💡 本题要点
1. 双指针是数组题的核心技巧，后面会遇到很多类似的
2. slow 指针只负责"非零区间的下一个空位"，fast 负责扫描
3. 时间复杂度 O(n)，空间复杂度 O(1) —— 只遍历了两次，没有额外空间
